# Wave Curves

WAV의 선택 구간을 푸리에 성분으로 분해하고, 성분의 합이 평면 곡선을 그리는 과정을 보여주는 독립 모듈입니다.

## 실행

**[실행용 HTML 다운로드](https://github.com/cksgus0561-dot/Wav/releases/latest/download/Wave-Curves.html)** · **[ZIP 다운로드](https://github.com/cksgus0561-dot/Wav/releases/latest/download/Wave-Curves.zip)**

`Wave-Curves.html` 하나에 코드·스타일·100초 예제가 모두 포함되어 있습니다. 다운로드한 HTML을 브라우저로 열면 됩니다. ZIP에는 같은 HTML 파일 하나가 들어 있습니다.

저장소의 `Wave Curves.html`도 동일한 단독 실행 파일입니다. `index.html`과 GitHub가 자동으로 제공하는 `Source code` 압축파일은 개발용 소스이며, `index.html`만 내려받아서는 실행되지 않습니다.

개발 시에는 Node.js 22 이상에서 `npm start`로 로컬 서버를 실행하고 <http://127.0.0.1:4173>에 접속합니다. 소스 수정 후 `npm run build`로 독립 HTML을 다시 생성합니다. `npm test`로 수학 및 WAV 디코딩 검증을 실행합니다. 외부 패키지 설치나 인터넷 연결은 필요하지 않습니다.

WAV를 열고 시작 위치·끝 위치 또는 구간 길이를 초 단위로 입력합니다. 입력 시간은 가장 가까운 원본 샘플 경계에 맞추며, 적용된 시간과 샘플 수를 표시합니다. 끝 위치나 길이를 바꾸면 시작 위치를 유지하며 파일 끝까지만 선택합니다. 시작 위치를 바꾸거나 파형을 클릭·드래그하면 길이를 유지한 채 구간을 이동합니다. 합성 성분 수를 조절하고, 재생·일시정지·시간 탐색으로 합성 과정을 확인합니다. 시각화 영역은 드래그로 이동하고 휠로 확대합니다. 처음 보이는 내장 예제는 긴 구간 검증에 사용한 48 kHz·100초 파형으로, 440 Hz와 713.37 Hz를 합성한 32-bit float 데이터입니다.

## 파형 확대와 이동

- 아래 파형에서 휠 또는 `+`·`−` 버튼으로 시간축을 확대·축소합니다. 휠은 마우스가 가리키는 시간을 기준으로 확대합니다.
- `선택 구간 보기`는 노란 분석 구간을 확대하고, `전체 보기`는 파일 전체로 돌아갑니다.
- 파형 바로 아래의 왼쪽·오른쪽 시간 숫자에 시작·끝 시간을 초 단위로 직접 입력할 수 있습니다. Enter를 누르거나 입력칸 밖을 클릭하면 해당 경계가 적용되며, 반대쪽 경계와 노란 분석 구간은 유지됩니다.
- Shift+드래그, `이동 모드`에서 드래그, 또는 `보기 위치` 막대로 좌우 이동합니다.
- 보기를 바꿔도 분석 구간은 유지됩니다. 일반 클릭·드래그는 화면에 보이는 시간에 맞춰 분석 구간을 이동합니다.
- 노란 분석 구간 양끝의 손잡이를 드래그하면 반대쪽 끝을 유지하며 구간 길이를 조절합니다. 드래그 중에는 범위를 미리 보여주고, 손을 놓으면 분석합니다. Esc로 취소할 수 있으며, 손잡이에 초점을 둔 상태에서 좌우 화살표를 누르면 한 샘플씩 조절합니다. 휴대폰에서는 손잡이를 손가락으로 드래그합니다.
- 넓은 구간에서는 다단계 최솟값·최댓값 요약을 사용하고, 충분히 확대하면 원본 샘플을 직접 연결해 표시합니다.

## 수학적 표현

WAV 샘플에 FFT를 수행해 각 사인파 성분의 진폭 A, 주파수 f, 위상 φ를 구합니다. 실수 사인파는 FFT의 양·음 주파수 쌍에 진폭이 나뉘므로 한 성분의 진폭을 구할 때 2/N을 곱합니다. DC와 짝이 없는 나이퀴스트 성분에는 1/N을 곱합니다. 성분을 진폭순으로 정렬하고 선택한 개수만큼 `A·exp(i(2πft+φ))`를 더합니다. 합의 실수부를 x, 허수부를 y에 표시합니다. 전체 성분을 사용하면 원래 샘플 위치에서 x가 입력값과 일치합니다.

곡선 표시용 격자에서는 같은 복소 지수 합을 역 FFT로 효율적으로 계산합니다. 마지막 점도 끝 시간의 합으로 계산하며, 첫 점으로 복사하거나 별도 선으로 경로를 닫지 않습니다. 유한 구간 FFT의 주파수는 `샘플레이트 / 샘플 수`의 정수배이므로 이 성분들의 합 자체는 주기적입니다.

선택한 유한 구간을 한 주기로 취급합니다. 양 끝의 파형값이 다르면 반복 경계의 영향이 생깁니다. 창 함수나 리샘플링을 자동 적용하지 않습니다. 회전각은 `2π × 주파수(Hz) × 구간 내 원본 시간(초) + 초기 위상`으로 계산합니다. 기본 재생 배율은 0.001×이며, 0보다 큰 유한한 배율을 직접 입력하고 Enter를 누르거나 입력칸 밖을 클릭해 적용합니다. 1×는 화면 1초당 원본 1초, 0.001×는 화면 1초당 원본 0.001초를 진행합니다. 재생 배율을 낮추면 모든 성분에 같은 배율을 적용하며, 분석 구간 길이는 회전 속도에 영향을 주지 않습니다. 구간 전체를 그리는 시간은 `샘플 수 / 샘플레이트 / 재생 배율`입니다. 화면 갱신이 늦어져도 경과한 시간을 반영하고, 일시정지·파일 읽기·숨겨진 탭에서는 진행을 멈춥니다. 원 가이드는 상위 64개까지, 합성 결과는 선택한 모든 성분으로 계산합니다.

한 바퀴를 완성한 곡선은 이후 반복 재생에서도 유지됩니다. 화면 갱신 사이에 한 바퀴 이상 진행해도 곡선이 사라지지 않습니다. 처음부터 그리기나 분석·합성 조건 변경은 궤적을 초기화하며, 시간 탐색은 지정한 위치까지의 궤적을 표시합니다.

긴 구간의 곡선은 작은 경로로 나눠 화면에 점진적으로 그린 뒤 재사용합니다. 확대·이동·화면 크기 변경 시 현재 시점에 맞춰 다시 그립니다. 분석 구간이나 선택한 푸리에 성분을 생략하지 않으며, 연결선만 화면상 0.25픽셀 미만의 인접 이동을 묶어 표시합니다. 최초 분석·합성 계산에는 여전히 구간 길이에 따른 시간과 메모리가 필요합니다. `tests/ui-long-window.mjs`는 48 kHz·100초 구간과 전체 2,400,001개 성분의 화면 표시 및 원본 샘플 재구성을 브라우저에서 검증합니다.

## 지원 범위

- RIFF/WAVE PCM 8·16·24·32-bit, IEEE float 32·64-bit, 해당 WAVE_FORMAT_EXTENSIBLE 파일.
- 원본 샘플레이트 유지. 다채널 파일은 분석 채널을 선택합니다.
- 파일당 최대 512 MB. 분석 구간은 1개 샘플부터 파일 전체까지 임의의 정수 샘플 길이를 지원합니다. 처리 가능한 큰 구간의 크기는 브라우저 메모리에 따라 달라지며, 긴 구간을 분석하는 동안 화면이 잠시 멈출 수 있습니다.
- 2의 거듭제곱 길이는 radix-2 FFT, 나머지는 Bluestein FFT로 정확한 선택 길이의 DFT를 계산합니다. 분석 구간을 늘리거나 잘라내지 않습니다. Bluestein의 내부 합성곱 패딩 및 곡선 표시용 보간 격자는 원본 분석 길이와 주파수 간격을 바꾸지 않습니다.
- RF64, RIFX, 압축 코덱 WAV는 현재 지원하지 않습니다.
- 브라우저 내 로컬 처리. 음원 재생 기능은 포함하지 않습니다.

## 다른 앱에 통합

`src/style.css`를 로드하고 `mountWaveCurves(element)`를 호출합니다. 반환된 객체의 `destroy()`로 이벤트, 애니메이션, 크기 관찰을 해제합니다. FFT와 WAV 읽기는 각각 `src/fourier.js`, `src/wav.js`에서 UI와 독립적으로 사용할 수 있습니다.
